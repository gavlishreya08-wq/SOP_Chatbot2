1. REQUIREMENTS FOR THIS PROJECT

Software:
- Python 3.10 or above
- pip
- Internet connection

Python packages:
- langchain
- openai
- faiss-cpu
- pypdf
- python-dotenv
- streamlit
- tiktoken
- langchain-community
- langchain-core
- langchain-groq
- langchain-text-splitters
- chromadb
- sentence-transformers
- pymupdf
- requests
- beautifulsoup4
- schedule

Environment variables needed in `.env`:
- GROQ_API_KEY=your_groq_api_key
- ADMIN_PASSWORD=your_admin_password

Optional `.env` variables:
- GEMINI_API_KEY=your_gemini_api_key
- GEMINI_MODEL=gemini-2.5-pro

Project folders/files used by the app:
- `sop_documents/`
- `img_txt/`
- `flowcharts/`
- `chroma_db/` (created/used for vector database)


2. INSTRUCTIONS TO RUN THIS PROJECT

Step 1: Open terminal in the project folder

Step 2: Create virtual environment
python -m venv venv

Step 3: Activate virtual environment on Windows
.\venv\Scripts\Activate.ps1

Step 4: Install dependencies
pip install -r requirements.txt
pip install langchain-community langchain-core langchain-groq langchain-text-splitters chromadb sentence-transformers pymupdf requests beautifulsoup4 schedule

Step 5: Create/update `.env` file with:
GROQ_API_KEY=your_groq_api_key
ADMIN_PASSWORD=your_admin_password
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-2.5-pro

Step 6: Run the main chatbot app
streamlit run app.py

Step 7: Open in browser
http://localhost:8501

Notes:
- On first run, the app may build or rebuild the vector database automatically.
- If `chroma_db` is missing, the app will create it.
- Admin panel can be run separately with:
streamlit run admin.py --server.port 8502
- Auto-sync service can be run with:
python run_auto_sync.py
